# Nintendo no GitHub

Guia em português, feito para celular, com os projetos ligados à Nintendo no GitHub (Switch, 3DS, Wii U, Wii/GameCube, DS, Game Boy, N64, SNES/NES, decompilações, Pokémon, amiibo): o que cada um faz, o que faz bem, exemplos e recomendações. Tem também a lista completa (2 mil+ repositórios) e um modo Tinder para ver um por vez.

Página: https://luisgabriel102.github.io/nintendo-github/

Gerado por `gerar.py` (levantamento de 26/11/2026).
